# Technical SEO Standards — Bucksworth

## Sitemap
- Generated by `src/app/sitemap.ts` in Bucksworth-Site
- All dates must be ISO 8601 with timezone (`2026-06-09T12:00:00Z`)
- Every indexable URL included (no pages missing from sitemap)
- Resubmit to GSC after any deploy that adds/removes pages
- Monitor GSC sitemap report weekly for errors (target: 0 errors)

## Canonical Tags
- Every page has a self-referencing canonical tag
- Pattern: `<link rel="canonical" href="https://www.getyourbucksworth.com/{path}" />`
- Always use `www.` prefix (metadataBase set in layout.tsx)
- No duplicate canonical targets (two pages pointing to the same canonical)
- Blog posts: canonical to self (not to service pages)

## Redirects
- All redirects are 301 (permanent)
- Managed in `next.config.mjs`
- Categories:
  - City slugs without `-az` → canonical `-az` URLs
  - Old WordPress paths → Next.js equivalents
  - WordPress remnants → homepage or relevant page
- Never chain redirects (A→B→C)
- Check for redirect loops before deploying

## Robots.txt
- Block: `/_next/static/`, `/_next/data/`, `/api/`
- Allow: everything else
- Sitemap reference: `Sitemap: https://www.getyourbucksworth.com/sitemap.xml`
- Never use robots.txt to prevent indexing (use noindex meta tag)

## Schema Markup
- All schema via JSON-LD in `<script type="application/json">` tags
- NO Microdata attributes (causes duplication with JSON-LD)
- Required schema per page type:
  - Homepage: Organization, LocalBusiness, WebSite
  - City pages: LocalBusiness, BreadcrumbList
  - Service pages: Service, FAQPage, BreadcrumbList, AggregateRating
  - Sub-service pages: Service, FAQPage, BreadcrumbList, AggregateRating
  - Blog posts: Article, FAQPage, BreadcrumbList
  - Landing pages: LocalBusiness, Service, AggregateRating

## Index Coverage Monitoring
- Weekly check of GSC Page Indexing report
- Track: indexed count, "Crawled - not indexed" count, "Discovered - not indexed" count
- Alert thresholds:
  - Indexed count drops 5%+ → immediate alert
  - "Crawled - not indexed" grows 10%+ → content quality review
  - New 404s appear → fix within 48 hours
- Target: 0 pages in "Crawled - not indexed" (indicates quality/duplicate issues)

## Page Speed
- Monitor key pages monthly with PageSpeed Insights API
- Priority pages: homepage, top 5 city pages, top 5 service pages
- Current baseline (Jun 2026): LCP 4.9s (RED), FCP 2.5s, TBT 10ms, CLS 0
- Target: LCP < 2.5s (requires investigation — likely image optimization)
- Image optimization: WebP format, lazy loading, proper sizing
- Font optimization: preload critical fonts, font-display: swap

## Security Headers
- HTTPS only (enforced by Vercel)
- HSTS enabled
- X-Frame-Options: DENY
- X-Content-Type-Options: nosniff
- CSP: appropriate for Next.js app

## Build & Deploy
- Vercel auto-deploys from `main` branch
- Monitor build times (currently acceptable, watch as content grows)
- data.json at 36MB — plan to split when it hits 50MB
- Consider ISR (Incremental Static Regeneration) for blog pages if build time > 10 minutes

# Targeting Decision Tree

## By Business Model

### SaaS / B2B (Viktor)

```
Monthly conversions?
├── <50
│   ├── Have a customer email list (500+)?
│   │   ├── Yes --> LAL 1% from customer list + Interest targeting
│   │   └── No --> Interest targeting only
│   ├── Interest stacks:
│   │   ├── Stack 1: Competitor tools (Slack, Asana, Monday, ClickUp, Notion)
│   │   ├── Stack 2: Role-based (Startup Founder, Small Biz Owner, Marketing Manager)
│   │   └── Stack 3: Tech/AI (Artificial Intelligence, Automation, Product Hunt)
│   └── Budget split: 70% interest prospecting, 30% retargeting
│
├── 50-200
│   ├── Test Advantage+ Audience with interest suggestions
│   ├── Build LALs from signup list (1-2%)
│   ├── Run broad test (one ad set) as a control
│   ├── Budget split: 50% LAL/Interest, 30% Advantage+/Broad test, 20% retargeting
│   └── Compare all approaches after 14 days, shift budget to winner
│
├── 200-500
│   ├── Primary: Broad targeting OR Advantage+ Audience
│   ├── Secondary: LAL 3-5% for incremental reach
│   ├── Consolidate interest ad sets (merge overlapping)
│   ├── Budget split: 60% broad/Advantage+, 25% LAL, 15% retargeting
│   └── Test ASC (Advantage+ Shopping) as incremental campaign
│
└── 500+
    ├── Primary: Broad targeting (remove all restrictions except geo/age)
    ├── Run ASC for 20-30% of budget
    ├── Minimal retargeting (algorithm handles this in broad)
    ├── Budget split: 70% broad, 20% ASC, 10% retargeting
    └── Only use audience restrictions for specific campaigns (geo expansion, vertical targeting)
```

### E-Commerce (General)

```
Monthly conversions?
├── <50
│   ├── Interest targeting around product category
│   ├── Competitor brand interests
│   ├── Lifestyle interests (who buys your category?)
│   └── LAL from email list if available
│
├── 50-200
│   ├── LAL 1-3% from purchasers
│   ├── Interest targeting (refined from data)
│   ├── Catalog/DPA retargeting
│   └── Test Advantage+ Audience
│
├── 200-500
│   ├── Advantage+ Shopping Campaign (primary growth)
│   ├── Broad prospecting CBO
│   ├── DPA retargeting
│   └── Consolidate interest campaigns
│
└── 500+
    ├── ASC (40-50% of budget)
    ├── Broad CBO (30-40%)
    ├── DPA retargeting (10-15%)
    └── International expansion
```

### Lead Generation

```
Monthly conversions?
├── <50
│   ├── Interest targeting (industry + role)
│   ├── Competitor interests
│   ├── Lead form retargeting (opened but didn't submit)
│   └── Consider optimizing for a higher-funnel event to get more data
│
├── 50-200
│   ├── LAL 1-2% from converted leads
│   ├── LAL from CRM customer list (if available)
│   ├── Test Advantage+ with suggestions
│   └── Website retargeting + lead form retargeting
│
├── 200-500
│   ├── Broad or Advantage+ primary
│   ├── LAL for expansion
│   ├── Tighten lead quality (optimize for downstream event if possible)
│   └── Consolidate
│
└── 500+
    ├── Broad primary
    ├── Value-based optimization (if you can pass lead values)
    └── Minimal audience restrictions
```

### App Install

```
Monthly installs?
├── <100
│   ├── Interest targeting (category users)
│   ├── LAL from existing users
│   └── Optimize for App Install initially, then deeper events as volume grows
│
├── 100-500
│   ├── Advantage+ App Campaign
│   ├── LAL from paying users
│   └── Optimize for in-app purchase or key event
│
└── 500+
    ├── Advantage+ App (primary)
    ├── Broad targeting
    └── Optimize for highest-value in-app event
```

## By Account Maturity Stage

### Nascent Account Checklist

Before targeting:
- [ ] Pixel installed and verified
- [ ] CAPI configured (if possible)
- [ ] At least one conversion event tracked
- [ ] Customer email list uploaded (if available)
- [ ] Exclusion audiences created (purchasers, existing users)

Targeting setup:
- [ ] 3-5 interest-based ad sets created
- [ ] 1 LAL ad set (if source audience exists)
- [ ] 1 retargeting ad set (website visitors)
- [ ] Each ad set has minimum 5x CPA daily budget
- [ ] Total audience sizes: 500K-5M per ad set

### Developing Account Checklist

Targeting evolution:
- [ ] Review interest ad set performance (keep top 2, pause rest)
- [ ] Build LALs from your own conversion data
- [ ] Test Advantage+ Audience in one ad set
- [ ] Test one broad ad set as a benchmark
- [ ] Check audience overlap between ad sets (merge if >30%)
- [ ] Expand LAL percentage if 1% is saturating

### Established Account Checklist

Targeting simplification:
- [ ] Primary campaign runs broad or Advantage+
- [ ] Interest targeting reduced to 1-2 ad sets max
- [ ] LAL expanded to 3-5%
- [ ] Retargeting consolidated to one campaign
- [ ] ASC campaign tested
- [ ] Audience overlap audit completed

### Advanced Account Checklist

Targeting optimization:
- [ ] Broad is primary (no audience restrictions)
- [ ] ASC running at 20-30% of budget
- [ ] Retargeting minimal (10-15% of budget)
- [ ] International expansion underway
- [ ] Incrementality testing in place
- [ ] Audience restrictions only used for specific strategic reasons

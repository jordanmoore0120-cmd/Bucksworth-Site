# Output CSV Specifications: Google Ads Editor Import Format

This file defines the exact CSV formats for all outputs generated by `mine_search_terms`. These formats are designed for direct import into Google Ads Editor. Follow the column order, quoting rules, and naming conventions exactly as specified.

---

## General CSV Rules

- Use comma as the field separator
- Encode as UTF-8 (no BOM)
- Quote any field that contains commas, quotes, or newlines
- Escape internal double quotes by doubling them (e.g., `"keyword with ""quotes""" `)
- First row is always the header row
- No trailing commas or blank rows at the end of the file
- Line endings: CRLF (\r\n) for maximum compatibility with Windows-based Google Ads Editor

---

## Negative Keyword CSV

**File name pattern:** `{account_slug}_negative_keywords_{YYYY-MM-DD}.csv`

**Columns (in order):**

```csv
Campaign,Ad Group,Keyword,Criterion Type,Status
```

**Column definitions:**

| Column | Description | Rules |
|--------|-------------|-------|
| Campaign | Campaign name for campaign-level negatives | Leave blank for account-level negatives. Leave blank for shared list negatives (handled separately). |
| Ad Group | Ad group name for ad-group-level negatives | Leave blank for account-level and campaign-level negatives. |
| Keyword | The negative keyword with match type formatting | Exact: `[keyword]`. Phrase: `"keyword"`. Broad: `keyword` (no brackets or quotes). |
| Criterion Type | Match type descriptor | One of: `Negative exact`, `Negative phrase`, `Negative broad` |
| Status | Keyword status | Always `Active` |

**Match type formatting in the Keyword column:**

| Match Type | Keyword Column Format | Criterion Type Value | Example |
|---|---|---|---|
| Exact | `[keyword here]` | Negative exact | `[knife sharpening jobs]` |
| Phrase | `"keyword here"` | Negative phrase | `"how to sharpen"` |
| Broad | `keyword here` | Negative broad | `free knife` |

Note: The Criterion Type column is technically redundant with the bracket/quote formatting in the Keyword column. Both are included because Google Ads Editor uses either one depending on the import method. Including both prevents mapping errors.

**Sort order within the file:**
1. Account-level negatives first (both Campaign and Ad Group blank)
2. Campaign-level negatives second (Campaign populated, Ad Group blank), sorted by Campaign name
3. Ad-group-level negatives last (both Campaign and Ad Group populated), sorted by Campaign then Ad Group

Within each level, sort by the original spend on the term descending (highest-waste terms first).

**Example:**

```csv
Campaign,Ad Group,Keyword,Criterion Type,Status
"","","jobs","Negative broad","Active"
"","","careers","Negative broad","Active"
"","","[knife sharpening salary]","Negative exact","Active"
"Non-Brand - Product","","[cheap knife set wholesale]","Negative exact","Active"
"Non-Brand - Product","","\"how to sharpen\"","Negative phrase","Active"
"Non-Brand - Product","Gift Sets","[wooden knife block]","Negative exact","Active"
```

**Import instructions for Google Ads Editor:**
1. Open Google Ads Editor
2. Select the target account
3. Go to Account > Import > From file (or Paste text)
4. Select the CSV file
5. Google Ads Editor will auto-detect the columns
6. If column mapping is requested, map: Campaign, Ad Group, Keyword, Criterion Type, Status
7. Review all changes in the "Proposed changes" panel
8. Verify account-level negatives appear under "Account > Negative keywords"
9. Verify campaign-level negatives appear under the correct campaigns
10. Click "Post" to apply changes to the account

## Keyword Expansion CSV

**File name pattern:** `{account_slug}_expansion_keywords_{YYYY-MM-DD}.csv`

**Columns (in order):**

```csv
Campaign,Ad Group,Keyword,Match Type,Max CPC,Final URL,Status
```

**Column definitions:**

| Column | Description | Rules |
|--------|-------------|-------|
| Campaign | Target campaign name | Must match an existing campaign name exactly, or use a new campaign name if recommended |
| Ad Group | Target ad group name | Must match an existing ad group, or use a new ad group name if creating one |
| Keyword | The keyword with match type formatting | Exact: `[keyword]`. Phrase: `"keyword"`. Broad: `keyword` (no brackets). |
| Match Type | Match type descriptor | One of: `Exact`, `Phrase`, `Broad` |
| Max CPC | Maximum cost-per-click bid | Leave blank if the campaign uses Smart Bidding (tCPA, tROAS, Maximize Conversions, Maximize Conversion Value). Only populate for Manual CPC or Enhanced CPC campaigns. |
| Final URL | Recommended landing page URL | Optional. Include if the search term suggests a specific landing page. Leave blank if the ad group's default URL is appropriate. |
| Status | Keyword status | `Active` for immediate activation. `Paused` for terms flagged for review-first. |

**Match type formatting in the Keyword column:**

| Match Type | Keyword Column Format | Match Type Value | Example |
|---|---|---|---|
| Exact | `[keyword here]` | Exact | `[best japanese chef knife]` |
| Phrase | `"keyword here"` | Phrase | `"japanese chef knife"` |
| Broad | `keyword here` | Broad | `japanese chef knife` |

**Sort order within the file:**
1. Active keywords first, then Paused
2. Within each status group, sort by conversion volume descending (highest-converting terms first)

**Example:**

```csv
Campaign,Ad Group,Keyword,Match Type,Max CPC,Final URL,Status
"Non-Brand - Product","Chef Knives","[best japanese chef knife]","Exact","","https://example.comjapanese_chef_knives","Active"
"Non-Brand - Product","Chef Knives","[8 inch chef knife]","Exact","","","Active"
"Non-Brand - Product","Knife Sets","[professional knife set]","Exact","","https://example.comknife_sets","Active"
"Non-Brand - Product","Knife Care","[knife sharpening stone]","Exact","","","Paused"
```

**Import instructions for Google Ads Editor:**
1. Open Google Ads Editor
2. Select the target account
3. Go to Keywords and targeting > Keywords
4. Go to Account > Import > From file
5. Select the CSV file
6. Map columns if prompted: Campaign, Ad Group, Keyword, Match Type, Max CPC, Final URL, Status
7. Review proposed changes
8. Verify keywords appear in the correct campaigns and ad groups
9. For new ad groups: Editor will create them automatically. Verify ad group settings after import.
10. Click "Post" to apply changes

## Shared Negative Keyword List CSV

**File name pattern:** `{account_slug}_shared_negatives_{YYYY-MM-DD}.csv`

This format is used when the analysis recommends adding negatives to shared negative keyword lists (rather than individual campaign or account-level negatives).

**Columns (in order):**

```csv
Shared Set,Keyword,Criterion Type
```

**Column definitions:**

| Column | Description | Rules |
|--------|-------------|-------|
| Shared Set | Name of the shared negative keyword list | Must match an existing shared list name, or specify a new list name to create |
| Keyword | The negative keyword with match type formatting | Same formatting rules as the Negative Keyword CSV |
| Criterion Type | Match type descriptor | One of: `Negative exact`, `Negative phrase`, `Negative broad` |

**Example:**

```csv
Shared Set,Keyword,Criterion Type
"Universal Negatives","jobs","Negative broad"
"Universal Negatives","careers","Negative broad"
"Universal Negatives","salary","Negative broad"
"Universal Negatives","hiring","Negative broad"
"Industry Negatives - Kitchen","[knife fighting]","Negative exact"
"Industry Negatives - Kitchen","\"knife crime\"","Negative phrase"
```

**Import instructions for Google Ads Editor:**
1. Open Google Ads Editor
2. Select the target account
3. Navigate to Shared library > Negative keyword lists
4. If the shared list does not exist, create it first: Add > Negative keyword list
5. Select the target list
6. Go to Account > Import > From file
7. Select the CSV file
8. Map columns if prompted
9. Review and post changes
10. After posting, verify the shared list is applied to the correct campaigns (under Campaign > Shared sets)

**Note:** Google Ads Editor import for shared lists can be inconsistent. If import fails, use the Google Ads web interface: Tools and Settings > Shared Library > Negative keyword lists. Add keywords manually or paste from the CSV.

## Output File Summary

| Output | File Pattern | Format | Import Target |
|--------|-------------|--------|---------------|
| Negative keywords | `{slug}_negative_keywords_{date}.csv` | CSV | Google Ads Editor > Keywords > Negative keywords |
| Expansion keywords | `{slug}_expansion_keywords_{date}.csv` | CSV | Google Ads Editor > Keywords > Keywords |
| Shared negatives | `{slug}_shared_negatives_{date}.csv` | CSV | Google Ads Editor > Shared library > Negative keyword lists |
| N-gram analysis | `{slug}_ngram_analysis_{date}.md` | Markdown | Reference document (not imported) |
| Conflict audit | `{slug}_conflict_audit_{date}.md` | Markdown | Reference document (not imported) |
| Summary dashboard | `{slug}_search_term_summary_{date}.md` | Markdown | Reference document (not imported) |

The three Markdown outputs (n-gram analysis, conflict audit, summary dashboard) are specified in the main SKILL.md file under Step 8. They are reference documents for the practitioner, not import files.
